About This Project

MediTrial Navigator

MediTrial Navigator is an educational portfolio prototype. It screens public ClinicalTrials.gov records against fictional patient profiles using simple, transparent rules.

What it checks

  • Available trial recruitment status
  • Related public condition text
  • Published minimum and maximum age fields
  • Available sex requirement fields
  • Whether eligibility text is available for human review

What it does not do

  • It does not diagnose a condition.
  • It does not recommend treatment.
  • It does not assess every eligibility rule.
  • It does not make a final enrollment or eligibility decision.
  • It does not use or accept real patient information.

Data source

Trial information is sourced from public ClinicalTrials.gov study records and stored locally for this educational demonstration.
